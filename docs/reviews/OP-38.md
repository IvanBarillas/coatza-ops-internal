# Identidad: contraseña inicial, correo verificado y TOTP

Los indicadores de contraseña provisional y correo ahora se cumplen en cada vista;
los administradores completan TOTP antes de operar. Incluye inscripción con QR
local, códigos de recuperación de un uso y reemplazo autenticado del dispositivo.

Closes OP#38

## Despliegue

Instalar el lock y aplicar migraciones django-otp y 0011 antes de operar. La BD real
no se migró. Las sesiones antiguas deben iniciar sesión nuevamente. SMTP real y
recuperación operativa deben verificarse en el entorno de despliegue.
Ver `docs/apps/identity-security.md` para orden de controles y límites.
