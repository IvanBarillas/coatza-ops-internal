# Sesiones: inventario personal y revocación remota

Mi cuenta incorpora sesiones paginadas con IP, navegador y actividad. Cada cuenta
puede revocar una sesión o todas las demás tras verificar contraseña; la siguiente
petición pierde acceso incluso en HTMX. La cookie no se expone en el inventario.
